⚙️ Settings

Yahan aap Cobalt API instance badal sakte ho. Default aapka apna instance set hai.

GET / par instance ka JSON aana chahiye. URL ke aage ?api= query se bhi set kar sakte ho.
Sirf agar instance auth maangta hai. Key browser ke localStorage mein save hoti hai.
Agar browser CORS block kare to ye relay use hoga. Jaise https://host/api/cobalt?api= — iske aage encoded API URL judta hai. GitHub Pages par ?relay= query se bhi de sakte ho.
